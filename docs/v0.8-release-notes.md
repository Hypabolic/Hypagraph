# Hypagraph v0.8

Hypagraph v0.8 adds interaction and approval nodes. A workflow can ask the user
a typed question, show a deterministic presentation, and continue independent
work while the question waits.

## Interaction nodes

- A node can enter `awaiting_response` without stopping the goal.
- Independent branches and loops stay runnable while a question waits.
- The person answers through a dialog. The model does not invent the answer.
- Closed questions publish declared facts. Open questions store a typed string
  fact that gates must not route on.

## Presentation, feedback, and deadlines

- Deterministic presentation kinds: `none`, `report`, and `command`.
- The durable order is request, presentation effect, presented observation,
  then dialog.
- Optional free-text notes and structured feedback artifacts reach the next
  task through explicit context projection.
- Absolute deadlines evaluate level-triggered on controller wake with `block`
  or `select` policies.

## Reload and product surface

- Outstanding questions survive reload and re-open after explicit resume.
- A completed presentation effect is not repeated when the artifact still exists
  or when regenerate fails after a successful observation.
- Status, widget, and graph pane show node-local and derived waiting state.
