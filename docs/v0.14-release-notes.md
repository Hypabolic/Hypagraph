# Hypagraph v0.14

Hypagraph v0.14 ships goal families, worktree concurrency, derived fan-out, and
external executor adapters. This cut includes roadmap milestones M7, M8, M8.1,
and M9 in one package release.

Plan markers v0.11–v0.13 are not published as separate tags. Their content is in
this release.

## M7 — Goal families and isolated Pi execution

- Goal-family persistence above workflow aggregates.
- One-member family projection for existing roots.
- Sequential family scheduler as the dispatch authority for family work.
- Bounded child-goal creation, return, and parent failure policies.
- Explicit executor context envelopes and structured result contracts.
- Current-session and isolated Pi RPC executors behind the same contract.
- Nested family graph and executor status surfaces.

A child Hypagoal is a workflow. A subagent-style run is one selected node attempt
on an executor. Only the controller commits canonical state.

## M8 — Worktrees and bounded concurrency

- Workspace lease contracts for safe concurrent mutation.
- Isolated git worktree prepare and release per mutating attempt.
- Structured worker commit results and pre-integration validation.
- Integration lifecycle with explicit conflict state.
- Post-integration base workspace checks (process-group termination, clean tree).
- Global and per-executor concurrency limits (default two isolated attempts).
- Concurrency groups and deterministic fairness.
- Concurrent selection for independent loops and child workflows.
- Crash recovery and stale integration rejection.

## M8.1 — Derived fan-out regions

- Expand a region from a typed collection fact with a declared maximum.
- Per-branch attempt lifecycle, evidence, and fan-in policy.
- Restore validation, attempt isolation, and untrusted-input diagnostics.
- Replay reproduces the same branch set from durable expansion state.

Fixed-width panels still need only authored nodes. Derived fan-out is for
counts that appear only at runtime.

## M9 — External executor adapters

- ACP executor adapter over child-process JSON-RPC.
- Named direct CLI executor adapters with invoke, cancel, timeout, and security limits.
- Shared JSON-RPC framing helper.
- Pi RPC, ACP, and CLI paths return the same structured result type for settlement.

## Suite

Run `npm run check` after install. Focused suites live under:

- `tests/m7-*` and `tests/goal-family-*`
- `tests/m8-*`
- `tests/m8.1-s1-derived-fan-out.test.ts`
- `tests/m9-*`

## Not in this release

- Named recipe library and The Gauntlet built-in (design only).
- Aggregate/synthesis product nodes from the deterministic orchestration plan
  (domain work remains open for fixed-width review quorums as a first-class node).
- A formal v1.0 hardening pass.
