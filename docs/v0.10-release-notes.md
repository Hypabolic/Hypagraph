# Hypagraph v0.10

Hypagraph v0.10 adds external effects and reconciliation. A node can change
external state safely, store lost knowledge as indeterminate, and reconcile on
restart without blind retry.

## Effect nodes

- An `effect` node holds an effect program, a reconciliation program, an
  idempotency policy, external identity facts, and an indeterminate policy.
- Durable effect states are `requested`, `observed`, and `indeterminate`.
- Schema version 8 stores effect observations on attempts.
- Replay restores effect state and never repeats the external call.

## Request before start

- The controller stores `requested` before it starts the external call.
- A lost result becomes `indeterminate`. It never becomes a silent success.
- Cancel, error, timeout, and interrupt after request are lost knowledge and
  stay indeterminate until reconciliation decides.

## Idempotency

- The idempotency key comes from canonical identity only: workflow, revision,
  node, and attempt.
- The host injects `effect.idempotency_key` and `effect.phase` into sandbox
  programs. Authors do not declare those names as fact inputs.
- A repeated attempt with the same key does not duplicate the external effect
  when the host honours the key.

## Reconciliation

- Each effect declares a read-only reconciliation program.
- Validation rejects a mutating reconciliation program.
- Restart promotes a durable `requested` attempt to indeterminate and recovers
  it before new work.
- The controller selects reconciliation before any new action.
- An unresolved indeterminate effect blocks its dependants, or fails the
  workflow when the policy says so.

## Execution success and external success

- Sandbox execution status and external observation stay separate fields.
- Only an external observation proves external success.

## Product surface

- Deterministic controller dispatch runs ready effects and reconciliations.
- Status, graph pane, and history show effect state and outcomes.
- Simulated dogfood uses an in-memory host. See `docs/m6-3-dogfood.md`.
